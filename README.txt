ANISAS Enterprise Cyber Intelligence Platform (Modules 01 - 07)

HOW TO RUN ON ANY COMPUTER / PC:

OPTION 1 (EASIEST - 1-CLICK LAUNCHER FOR WINDOWS):
- Double-click "run.bat" directly in this unzipped folder!
- It automatically installs all Python requirements and opens http://localhost:8000 in your web browser!

OPTION 2 (MANUAL LAUNCH VIA TERMINAL):
1. Open Terminal / PowerShell in this folder.
2. Navigate to ai-service: cd ai-service
3. Run: pip install -r requirements.txt
4. Run: python main.py
5. Open browser at: http://localhost:8000
